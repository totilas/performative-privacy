# Performative Privacy Simulation & Theoretical Bounds

This repository contains the codebase for simulating and theoretically modeling the optimal noise scale ($\gamma$) in a performative prediction environment. It compares exact theoretical closed-form objectives against empirical Monte Carlo simulations across a grid of population leave ($q$) and join ($r$) probabilities under specific privacy thresholds ($\tau$).

## 📁 Repository Structure

### Core Simulation

* **`single_q_r.py`**: Runs a discrete-time simulation for a single pair of leave and join probabilities ($q$ and $r$). It tracks dataset sizes and empirical errors across a finite time horizon of 50 steps, saving the resulting data as atomic pickle files to prevent data corruption.


* **`launch_all_grid.py`**: Uses a `ThreadPoolExecutor` to run independent $q$ and $r$ experiments in parallel. The script accepts a `--workers` argument to limit the number of simultaneous simulations.



### Data Processing & Theoretical Computations

* **`perf_priv_mia_mean_theory_heatmap.py`**: Executes a 30x30 grid search to minimize a closed-form cumulative error objective. It calculates the optimal noise scale ($\gamma$) and exports the findings to both a text file and a matplotlib heatmap.


* **`pickle_to_text_emp.py`**: Parses the empirical pickle files generated by the simulations to locate the specific $\gamma$ value that minimizes error for a target privacy threshold ($\tau$). The script extracts these findings and saves the optimal gamma summaries to a text file.


* **`ptau_generation.py`**: Computes the marginal leakage probability for various $\gamma$ scales. It generates 200,000 clipped Monte Carlo samples and plots the integral results against the privacy threshold $\tau$.



### Visualization & Comparison

* **`c_gamma_comparison.py`**: Ingests simulation results to build line plots comparing theoretical and empirical population growth factors. The script visualizes data specifically for $\tau$ values of 0.02 and 0.05, applying shaded bands to represent one standard deviation.


* **`perf_priv_theory_practice_compare.py`**: Reads the parsed empirical and theoretical text files to generate side-by-side comparative heatmaps. It applies paper-friendly formatting to matplotlib configurations and outputs standalone line comparisons of the optimal $\gamma$ values.

## 🚀 Execution Workflow

Follow these steps to reproduce the theoretical bounds, run the empirical simulations, and generate the comparative figures.

**1. Run the Empirical Grid Simulations**
Launch the parallelized grid search to simulate the performative dynamics over a range of $q$ and $r$ values.

```bash
python launch_all_grid.py --workers 4

```

*Results will be saved as `.pkl` files in the `results/` directory.*

**2. Generate Theoretical Optimal Gammas**
Run the theoretical optimizer to calculate the closed-form optimal noise scales.

```bash
python perf_priv_mia_mean_theory_heatmap.py

```

*This produces `optimal_gammas_theory_0.02.txt` and a theoretical heatmap image.*

**3. Extract Empirical Gammas**
Extract the summarized optimal gammas from the simulation pickle files into a standard text format.

```bash
python pickle_to_text_emp.py

```

*This parses the `results/` folder and outputs `optimal_gammas_empirical_0.02.txt`.*

**4. Generate Comparative Visualizations**
Run the comparison scripts to generate paper-ready plots validating theory against practice.

```bash
# Compare the theoretical and empirical optimal gamma heatmaps and lines
python perf_priv_theory_practice_compare.py

# Compare the population growth factors (C_T) across gammas
python c_gamma_comparison.py

# Generate the marginal leakage probability (p_tau) curves
python ptau_generation.py

```
